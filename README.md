# Survival Log Recipe Finder

A non-commercial, unofficial fan-made recipe finder for **Survival Log**.

> **Public Beta v0.1** — based on the stable R18.5 build.

## What it does

- Search ingredients and track what you currently have
- Find related recipes and recipes you can make now
- Handle exact-ingredient recipes and generic TagCombo recipes
- Apply cooking-tool and cooking-level filters
- Compare satiety, efficiency, recovery, morale, stamina, cooking time, EXP, and trade value
- Calculate electric-hotpot results
- Switch between Korean, English, and Simplified Chinese
- Show in-game ingredient/recipe icons for quick identification

## Usage

Open `index.html` in a modern browser, or deploy this repository with GitHub Pages. No server or build step is required.

## Data version

The recipe/calculation dataset is based on **Survival Log 1.0.16756**. English and Simplified Chinese localization strings were mapped from official game localization data available during development.

This project may become inaccurate after game updates.
